# Community servers

Servers that anyone can join. The launcher lists every server in the community network under **Browse servers**, with your ping and how many are online. This page also lists servers outside it.

## The community network

Servers that share friends through the community coordinator, `https://coord.scbl.jdevwebb.net`. Friends and names follow players between them.

| Server | Address | Region | Friend lists | Run by |
|---|---|---|---|---|
| 5th Echelon Community | `play.scbl.jdevwebb.net` | — | mutual | [JDevWebb](https://github.com/JDevWebb) |

**To add yours:** install it with [the installer](deploying.md), then [open an issue](https://github.com/JDevWebb/5th-echelon-enhanced/issues/new?template=add-server.yml). Once it's checked, you get the join token privately and your server joins the directory. You can also send a pull request adding it to this table.
