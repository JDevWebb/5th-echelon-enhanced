The first public release of 5th Echelon Enhanced: free community servers for *Splinter Cell: Blacklist* multiplayer, and a launcher that sets the game up for you. Co-op and Spies vs Mercs, with no VPN and no port forwarding.

## Play

1. Download **`launcher.exe`** (Windows) or **`launcher-linux-x86_64`** (Linux, Steam Deck) below.
2. Run it. It finds your game, and under **Choose a server** picks the community server closest to you: Europe, North America or Oceania.
3. Press **Connect**, pick the name other players will see, then **Play**. Press <kbd>F5</kbd> in the game for friends and invites.

**Used upstream 5th Echelon before?** Use this launcher instead of the old one; there's nothing to uninstall. It replaces the old client in your game folder (keeping the game's original file), and your settings and saves carry over. Your old server stays selected: to play on the community servers, open **Servers** and press **Switch** on the closest. Played over Radmin VPN or Hamachi? You don't need it here, and the Status card fixes the network adapter setting it left behind. More in [Play in five minutes](https://github.com/JDevWebb/5th-echelon-enhanced#play-in-five-minutes).

## Everything new since upstream 5th Echelon 0.2.5

### Playing

**Internet play without a VPN**
- The server's NAT helper tells your game its public address, so the game advertises it and connects to other players directly.
- The client asks your router to open the game's port (UPnP, then NAT-PMP).
- When neither gets through (no port forward, mobile hotspots, carrier-grade or symmetric NAT), your matches go through the server's relay. Hosts without a port forward can be joined that way too.
- The relay carries the game's largest packets, so co-op missions load over it, with one or both players relayed.
- The server corrects the address a game registers if it picked the wrong network adapter, and `trusted_subnet` does the same for groups on a VPN.

**Matches and invites**
- Co-op and Spies vs Mercs: Find Teammate, Quick Match, lobby invites, and invites into private matches ([#123](https://github.com/unixoide/5th-echelon/pull/123) by Matthias Walther), with follow-up fixes so they arrive reliably.
- A party follows its host into a private match, and an invited player who left a match can get back in.
- Private matches stay private: never offered to Find Teammate or Quick Match, and joined only by invitation or with the host's party.
- Leaving a session removes you from it, and empty sessions end, so matchmaking no longer offers abandoned lobbies.

**Friends**
- Real friend lists instead of "everyone on the server": friend requests, blocking and player search in the in-game overlay (<kbd>F5</kbd>).
- Friends-only lists and invites on public servers.
- Friends follow you to every server in the community network, and the overlay and launcher show which server they're on, with one click to join them.
- Your name is reserved across the network, you can rename your account, and the overlay warns when someone uses a friend's name elsewhere.

**One identity, every server**
- The launcher makes you an identity, a key that stays on your PC, and links your accounts to it. It finds your account on any server by itself: no username or password to remember.
- Moving PCs: import your identity on the new one, and you're signed in everywhere.
- Each server gets its own random password (upstream reused one everywhere), saved encrypted on Windows.

**The launcher**
- Rewritten and redesigned, for Windows and Linux (Steam, Flatpak, Steam Deck, Lutris, Heroic).
- A guided first-run setup: finds the game, installs the client (keeping the game's original file), finds or makes your account, pins the right network adapter, and makes a rank 5 save so co-op and Spies vs Mercs are unlocked.
- A Status card that checks your setup and fixes what's wrong, including the network adapter Radmin or Hamachi left behind, and a note when a VPN sits between you and the server.
- The community network by default: it pings every server, picks the closest, and **Switch** moves you to another with your name and friends.
- Server news, online friends and your profile on the home screen.
- Save games: a new rank 5 save, raising an existing one to rank 5 (with a backup first), importing your Ubisoft Connect save, and backups.
- Updates itself from signed releases, at start, every 4 hours, and at once when a server says it's outdated. The launcher and the client it installs are always the same version.
- Opens in virtual machines without OpenGL 2.0 (Direct3D 12 on Windows).
- Settings are never silently reset: an unreadable file is kept, and outside changes are merged.
- A Host screen to run a server on your own PC, and a management screen for your server, local or over an SSH tunnel.

**The game client**
- Works under Wine and Proton: the network check Wine lacks is emulated ([#128](https://github.com/unixoide/5th-echelon/pull/128) by Thiago), it starts without Ubisoft Connect, and it no longer starts a thread per CPU core.
- Signs in again by itself when the server restarts or your sign-in lapses.
- A redesigned overlay, with friends, invites, lobby player limits and server status.
- Tells the game when your friend list changes, so a new friend can show up without a restart.
- Crash fixes, and `uplay.override.toml` for tools that set up the game.

### Running servers

**One script for a server**
- `install-server.sh` sets up a server on a fresh Linux VPS: a sandboxed systemd service, Caddy with automatic HTTPS, firewall rules, and updates that check the release's signature. `--status` shows how it's doing.
- `harden-host.sh` hardens the machine: SSH keys only (optionally on another port, with an automatic undo if you'd be locked out), fail2ban, kernel settings, and automatic updates with reboots at a quiet hour.
- Also runs on Windows (from the launcher's Host screen), in Docker, and behind a reverse proxy.

**A network of your own**
- A coordinator shares friends between your servers, reserves names across them, and lists them in a server directory players set up from.
- It rolls out each signed release to its servers, one first and then the rest; each server checks the signature again and puts the previous release back if the new one doesn't come back healthy.
- An admin UI: players and cities on a map, what's being played, pings, each server's CPU, memory and bandwidth live, bandwidth and player reports, the update rollout, and alerts to Discord or Slack. Sign-in with passkeys or an authenticator app, behind Cloudflare.
- Servers refuse launchers and clients older than they allow, so everyone plays on versions that work together.

**Stability**
- Bad packets can no longer crash the server, a failed service restarts the process, and matchmaking no longer panics on odd data.
- Sign-ins survive server restarts, presence works, and memory no longer grows without bound.
- Load-tested to 1,000 players on two CPU cores ([results](https://github.com/JDevWebb/5th-echelon-enhanced/blob/main/docs/load-testing.md)).

### Security

A security audit of the server, the client, the launcher, the coordinator and the installer, with every finding fixed:
- **Game client:** data from a server can no longer overflow the game's memory, and a server can't put you in a match without your click.
- **Game server:** caps on packets, fragments and connections; replies only to a connection's own address; logins checked first; plain logins can no longer sign in as someone else; sample accounts disabled.
- **Accounts:** rate limits and lockouts on sign-ins, tickets and tokens that expire (and end when the password changes), blocks that stay invisible, and activity shown to friends only.
- **Identities:** a signature works only for the server you connected to, so a malicious server can't replay it elsewhere.
- **Internet play:** the NAT helper and relay only serve signed-in players, with tags on relayed packets and rate limits.
- **Coordinator and admin UI:** servers can't act for each other; Argon2id passwords, passkeys, TOTP and recovery codes, CSP and CSRF checks, and an audit log.
- **Updates:** the launcher, the installer and the servers install only releases signed with the release key, which never meets the build; downloads carry build provenance.
- **HTTPS** for sign-ins wherever a server has a domain, and the admin API is never reachable from the internet.

Found a security problem? Please report it privately: see [SECURITY.md](https://github.com/JDevWebb/5th-echelon-enhanced/blob/main/SECURITY.md).

## Good to know

- **Antivirus:** the launcher and the client DLL aren't code-signed yet, and some antivirus programs flag new game tools that install a DLL. Check your download against the verification details below, and see [Antivirus warnings](https://github.com/JDevWebb/5th-echelon-enhanced#antivirus-warnings).
- **You need your own copy of the game.** Nothing of the game is included.
- **Free, and provided as is,** without warranty of any kind (see the [licence](https://github.com/JDevWebb/5th-echelon-enhanced/blob/main/LICENSE.md)).
- **What's next** is on the [roadmap](https://github.com/JDevWebb/5th-echelon-enhanced/blob/main/docs/roadmap.md): the first code-signed builds, and play between players on different regional servers.
