# 0.4.7 "Clear Channel"

A fix for 0.4.6: on a busy server, chat, friend lists and signing in could take many seconds or time out, and the game said you'd lost the server. They answer straight away again.

> [!TIP]
> **Thank you to Gex and Tea_bag**, whose Support message and report showed it within hours of 0.4.6.
>
> Send yours from **Settings › Feedback › Send feedback**.

## Play

Already on 0.4.5 or 0.4.6? The launcher updates itself. New here? Download **`launcher.exe`** (Windows) or **`launcher-linux-x86_64`** (Linux, Steam Deck) below, run it, press **Connect**, then **Play**. More in [Play in five minutes](https://github.com/JDevWebb/5th-echelon-enhanced#play-in-five-minutes).

Coming from 0.4.5? Everything in [0.4.6](https://github.com/JDevWebb/5th-echelon-enhanced/releases/tag/v0.4.6) is in this one too: chat, Join, Play SvM and Play Coop, and the rest. The launcher shows it after the update.

## What's fixed

- **The launcher's API on servers behind Caddy** (every server the installer sets up). Caddy carries all players' calls over a few connections to the server, which ran only 4 calls at a time on each. Chat's waits for new messages (0.4.6) are held for up to 25 seconds, so a handful of players' waits held up everyone else's sign-ins, friend lists, chat and reports. A connection now runs every call it has open, and Caddy opens another once one is full. `scripts/proxy-test.sh` checks it with calls held open through Caddy.

## Running servers

- **Update as usual**: the rollout in an update window, or the installer by hand. Only the server changed; nothing else is needed.
- **Correction to 0.4.6's steps for moving a coordinator to a new name:** each member server needs its join token as well, `--coordinator https://<new> --join-token-file token.txt` (from `--show-join-token` on the coordinator's machine). Without it the server logs "not joined yet, and [federation] join_token is empty" and stops sending heartbeats. [failover.md](https://github.com/JDevWebb/5th-echelon-enhanced/blob/main/docs/failover.md#moving-a-coordinator-to-a-new-name) says so now.
- **The roadmap's next release is 0.4.8**: global matchmaking, the lobby browser and fair play, as planned for 0.4.7.
